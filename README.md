# 🌱 心流花园 · Mind Garden

> *"写下你的思考，种下你的心念。每一次落笔，都在星空里点亮一颗星。"*

---

## 📖 项目简介

**心流花园**是一个将**哲学反思、AI 情绪分析与数字艺术**深度融合的桌面应用。它不只是一个写作工具，更是一个**内心的数字圣殿**——一个你可以随时回来、与自己对话的空间。

在这里，你的每一个想法都会被 DeepSeek AI 精准捕捉情绪，化作一颗**独特的、会呼吸的光球**，在 3D 星空花园中生长。花园会随着时间**旋转、呼吸、演化**——就像你的内心世界。来自东西方哲学的 50+ 深度问题会引导你更深入地理解自己，五层泛音环境音景根据情绪微妙变化，营造沉浸式的反思体验。

**核心理念：书写即疗愈，可视化赋予意义，每一次反思都是创造。**

---

## 💡 创作缘由

在快节奏的数字时代，我发现了一个普遍的困境：

1. **我们每天都在消费信息，却很少消化感受。** 社交媒体让我们习惯了快速滑动、点赞、划走，但我们很少停下来问自己："我现在真正感受到的是什么？"

2. **写作是最古老的自我疗愈方式，但它被异化了。** 写作变成了工作报告、学术论文、社交媒体文案——我们忘了，写作最初是为了理解自己。

3. **抽象的内心世界需要被"看见"。** 我们的情绪、思考、感悟都是无形的。当它们不可见时，我们很难珍视它们。但如果每一个想法都变成一颗会发光的星呢？

4. **AI 不应该只是工具，它可以是理解我们的镜子。** 大语言模型有能力理解人类情感的细微质地——为什么不用它来帮助我们更好地理解自己，而不是替代我们思考？

这个项目是我对这些问题的回答。

## 🎯 特性

### 🧠 AI 情绪分析引擎
- **DeepSeek AI 驱动**：调用 DeepSeek V3 大语言模型，以哲学家 + 心理学家的视角理解文字中的情感质地
- **40+ 情绪标签**：覆盖暖色系（喜悦、感激、希望、爱…）、冷色系（悲伤、忧郁、迷惘…）、中性（思考、宁静、释然…）
- **智能回退机制**：当 API 不可用时，自动切换到内置的 20 组关键词匹配引擎，确保离线可用
- **深度解读**：AI 不仅标注情绪，还提供一句话深度情感分析和引导性反思问题
- **多标签标记**：每条心念有 1-3 个副情绪标签，更精准地描述复杂心情
- **实时预检测**：打字过程中，前端实时进行关键词情绪预检，即时反馈

### 🌸 3D 星空花园
- **Three.js 驱动**：每个想法都是一个**带有双层光晕和轨道环的发光球体**，暖色情绪球体更大更亮
- **2000 颗背景星空**：蓝紫色调，缓慢旋转营造宇宙感
- **呼吸动画**：每个球体以各自独立的节奏上下漂浮、光晕脉动、自转
- **轨道控制**：OrbitControls 支持旋转、缩放、平移探索花园
- **点击交互**：点击球体查看详情面板（情绪、正文、AI 标签、深度分析、时间戳），点击空白处随机浮现一段回忆
- **三模式切换**：
  - ✍️ **书写模式**——卡片为主，花园作为暗淡背景
  - ✨ **花园模式**——全屏沉浸 3D 探索，覆盖层显示情绪分布条和主导情绪
  - 📖 **回忆模式**——时间线浏览所有过往心念

### 🌌 粒子背景系统
- **Canvas 2D 渲染**：数百个动态粒子，每个有独立的呼吸相位、大小、透明度
- **鼠标交互**：粒子靠近鼠标时变亮变大
- **写作响应**：聚焦 textarea 时，粒子变得更活跃
- **绽放特效**：提交心念时，40 个粒子从输入区中心绽放，带有重力模拟
- **色彩系统**：粒子色调随鼠标位置和呼吸状态微妙变化

### 🎵 环境音景
- **Web Audio API**：五层正弦波泛音（A1 55Hz → E2 82Hz → A2 110Hz → A3 220Hz → E4 330Hz）
- **低频调制**：每个振荡器由独立的 LFO（0.03-0.09Hz）轻微频率调制，营造"呼吸感"
- **情绪响应**：不同情绪微调音色比率（喜悦 1.03x、悲伤 0.98x、宁静 1.0x…）
- **优雅淡入淡出**：首次点击页面后 3 秒淡入，切换页面时 1.5 秒淡出
- **失谐设计**：每个音层有 ±1.5Hz 的随机失谐，避免过于"完美"的电子感

### 🧘 哲学提示库
- **50+ 精心挑选的反思问题**，来自东西方哲学传统：
  - 🌅 **日常之问**（15 题）——关注当下的感受和体验
  - 🧠 **深度哲思**（12 题）——斯多葛、道家、存在主义、禅宗的叩问
  - 🎨 **诗意之问**（10 题）——用隐喻和意象打开想象力
  - 💞 **关系之镜**（7 题）——通过与他人的关系反观自我
- **每日一问**：基于日期哈希，同一天展示同样的问题
- **随机换题**：随时切换问题寻找灵感

### 🎨 设计系统
- **玻璃态 UI**：backdrop-filter 模糊 + 微妙边框，营造深度感和层次感
- **暗色深邃基调**：#080816 深空背景，让色彩从黑暗中浮现
- **情绪色彩映射**：40+ 情绪各对应独特颜色（暖色系金黄/粉，冷色系蓝/紫，中性色系薄荷/灰蓝）
- **呼吸引导环**：右下角 6 秒周期脉动（4 秒吸气 / 4 秒呼气），CSS 动画驱动
- **响应式排版**：Georgia + Inter + 思源宋体 + PingFang SC 字体栈
- **平滑过渡**：三级贝塞尔曲线过渡系统（slow 0.6s / medium 0.35s / fast 0.18s）

### 🖥️ 桌面应用体验
- **Electron 封装**：原生窗口、单实例锁、上下文隔离
- **内嵌 Express 服务器**：主进程通过 child_process.fork 启动服务端
- **环境自适应**：开发模式自动打开 DevTools，打包模式使用 resources/data/ 存储
- **便携版构建**：自定义 asar 打包脚本，智能过滤 node_modules（仅保留运行时依赖）
- **一键启动**：Windows 便携版双击即用，无需安装 Node.js

### 📝 种子数据系统
- **30 条有温度的模拟日记**：如真人两周内的碎碎念，覆盖喜悦、感激、悲伤、孤独、释然等全情绪光谱
- **冷暖分布分析**：播种完成后自动统计暖色系/冷色系/中性情绪占比
- **可视化播种过程**：每条日记显示 AI 标注的情绪、标签、和内容预览

## 🏗️ 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| **桌面框架** | Electron 42 | 将 Web 应用封装为原生桌面体验 |

## 🚀 快速部署

### 方式一：直接运行（开发模式）

```bash
# 1. 克隆仓库
git clone https://github.com/ly99LLL/park-every.git
cd park-every

# 2. 安装依赖
npm install

# 3. （可选）配置 AI 情绪分析
# 复制环境变量模板
cp .env.example .env
# 编辑 .env，填入 DeepSeek API Key（从 https://platform.deepseek.com/api_keys 获取）
# DEEPSEEK_API_KEY=sk-your-api-key-here

# 4. 启动花园（Web 模式）
npm start

# 5. 浏览器访问
open http://localhost:3000
```

> 💡 **不配置 API Key 也能正常使用！** 系统会自动使用内置的关键词情感分析引擎。配置 DeepSeek API Key 后会获得更精准的 AI 情绪标注和深度解读。

### 方式二：Electron 桌面应用

```bash
# 在项目目录中启动 Electron 窗口
npm run electron

# 开发模式（自动打开 DevTools）
npm run electron:dev
```

### 方式三：构建 Windows 便携版

```bash
# 自动打包为免安装的 .exe 文件
npm run build:dir

# 打包为 NSIS 安装包
npm run build

# 输出位置：dist/MindGarden-win32-x64/
# 双击「心流花园.exe」或「启动心流花园.bat」即可运行
```

### 播种演示数据

```bash
# 启动服务器后，运行种子脚本
# 将会通过 API 提交 30 条有温度的模拟日记
node scripts/seed-garden.js
```

## 💎 项目意义

### 对用户的意義

1. **提供一个"第三空间"**：不是工作，不是社交，而是一个只属于自己的内心空间。在这个永远在线的时代，有一个可以"离线"面对自己的地方，本身就是一种奢侈。

2. **让情绪被看见**：很多人说不清自己是什么感觉。当一个 AI 对你说"你写的这段文字，底色是'怅惘'"——这个命名本身就是一种疗愈。被准确地理解，是人类的深层需求。

3. **可视化创造意义感**：当你看到 30 颗不同颜色的星在夜空中漂浮，你会意识到——"这些都是我。有喜悦的我，有悲伤的我，有困惑的我。它们都是我，都值得被珍视。"

4. **引导而非说教**：没有"你应该感到快乐"的压力。花园接受所有情绪——悲伤的蓝色星和喜悦的金色星同样美丽。这本身就是一种无声的接纳。

### 对技术的意義

1. **AI 的另一种可能**：当所有人都在用 AI 提高效率、自动化工作流时，这个项目展示了 AI 的另一种角色——帮助我们理解自己，而不是替代我们思考。

2. **桌面应用的艺术性**：Electron 应用不必只是"网页套壳"。精心设计的粒子系统、3D 渲染、音频生成——让桌面应用成为一种数字艺术体验。

3. **离线优先的 AI 体验**：AI 能力不应该依赖网络。内置的关键词引擎确保了核心体验在任何环境下都可用。

## 📂 项目结构

```
interesting/
├── main.js                 # Electron 主进程
├── preload.js              # 安全的 IPC 桥接
├── server.js               # Express 服务器入口
├── package.json            # 项目配置 & 构建脚本
├── .env.example            # 环境变量模板
├── .gitignore
├── src/
│   ├── ai.js               # DeepSeek AI 情绪分析引擎 (287行)
│   ├── db.js               # SQLite 数据库层 (172行)
│   └── prompts.js          # 哲学提示库 + 关键词情感分析 (138行)
├── public/
│   ├── index.html          # 主应用（全部前端逻辑，约1420行）
│   ├── icon.png            # 应用图标
│   └── styles/
│       └── main.css        # 完整样式系统 (约600行)
├── scripts/
│   ├── build-portable.js   # 便携版构建脚本
│   └── seed-garden.js      # 30条演示数据播种脚本
├── data/
│   └── garden.db           # SQLite 数据库（运行时生成）
└── dist/
    └── MindGarden-win32-x64/  # 构建输出
```
