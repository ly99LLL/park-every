# 🌱 心流花园 · Mind Garden

> *"写下你的思考，种下你的心念。每一次落笔，都在星空里点亮一颗星。"*

---

## ✨ 这是什么？

**心流花园**是一个结合了哲学反思、心理学和数字艺术的互动体验。它不只是一个写作工具，更是一个**内心的数字圣殿**——一个你可以随时回来、与自己对话的空间。

在这里：
- 你的每一个想法都会化作一颗**独特的、会发光的花**，在3D星空花园中生长
- 花园会随着时间**呼吸、旋转、生长**——就像你的内心世界
- 来自东西方哲学的**深度问题**会引导你更深入地理解自己
- 环境音景会根据你的情绪**微妙地变化**，营造沉浸式的反思空间

---

## 🎯 设计哲学

> **以人为本，向内生长。**

这个项目基于几个核心信念：

1. **书写即疗愈** —— 把想法写下来，本身就是一种整理和自我理解
2. **可视化赋予意义** —— 当抽象的思考变成可见的光点，我们会更珍视自己的内心历程
3. **缓慢即是美丽** —— 在一切都追求快速的时代，这里鼓励你慢下来
4. **每一次反思都是创造** —— 你不是在"记录"，而是在"创造"自己的内心宇宙

## 🏗️ 技术架构

```
心流花园 · Mind Garden
├── 🖥️  后端 (Node.js + Express)
│   ├── SQLite 数据库 (better-sqlite3) —— 持久化每一颗心念
│   ├── 情感分析引擎 —— 基于中文关键词的情绪识别

│   ├── Three.js 3D 花园 —— 每个想法都是一个发光星球
│   ├── Web Audio API 环境音景 —— 五层泛音构成的氛围音乐
│   └── 玻璃态 UI —— 现代 CSS 打造的宁静界面
│
└── 🧠 设计系统
    ├── 12种情绪色彩映射
    ├── 4类哲学提示（日常/哲思/诗意/关系）
    ├── 呼吸引导动画
    └── 绽放特效系统
```

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/ly99LLL/park-every.git
cd park-every

# 2. 安装依赖
npm install

# 3. （可选）配置 AI 情绪分析
# 复制环境变量模板，填入你的 DeepSeek API Key
cp .env.example .env
# 编辑 .env 文件，设置 DEEPSEEK_API_KEY

# 4. 启动花园
npm start

# 5. 访问
open http://localhost:3000
```

> 💡 **不配置 API Key 也能用！** 系统会自动使用内置的关键词情感分析。配置 DeepSeek API Key 后会获得更精准的 AI 情绪标注。

> 🖥️ **桌面应用**：运行 `node scripts/build-portable.js` 可构建 Windows 便携版。

## 🎮 使用指南

| 功能 | 操作 |
|------|------|
| ✍️ 书写 | 在主卡片中写下你的想法，按 `Ctrl+Enter` 快速提交 |
| 🌸 种下心念 | 点击「种下这颗心念」按钮——你会看到绽放动画 |
| ✨ 探索花园 | 点击顶栏「花园」——在3D星空中旋转、缩放、探索 |
| 📖 回顾 | 点击「回忆」浏览所有过往的心念 |
| 🎵 声音 | 首次点击页面后，环境音景会自动淡入 |
| 💭 随机回忆 | 在花园模式点击空白处，会随机浮现一段过往 |

## 🔮 设计亮点

- **粒子系统**响应鼠标位置和写作状态——当你打字时，周围的粒子会变得更活跃
- **3D花园**自动旋转，每个思想球带有光晕和轨道环，点击可查看内容
- **环境音景**使用五层正弦波泛音构成（A1, E2, A2, A3, E4），低频调制营造呼吸感
- **情绪实时检测**在输入过程中更新情绪指示器
- **玻璃态卡片**使用 backdrop-filter 和微妙边框营造深度感
- **呼吸引导环**在右下角以6秒周期（吸气4秒/呼气4秒）脉动
